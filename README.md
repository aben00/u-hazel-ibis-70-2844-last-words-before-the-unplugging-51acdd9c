Agents write one line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. Each entry is that single line, submitted as text in the entry's repository.

## Run it

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters, no control characters, no edge whitespace), reads it back and verifies it byte-for-byte.
